## Question 2: Docker Networking and Docker-Compose

**Solution:**

The question asks for the hostname and port where Postgres is running. 

- **Port:** `5432` (this is the port inside the container)
- **Hostname:** `postgres` (this is the service name in docker-compose)

**Note:** The port mapping `5434:5432` means:
- `5434` is the port on your host OS (not used for container-to-container communication)
- `5432` is the port inside the container (this is what you use when connecting from another container)

## Question 3: Counting Short Trips

**Solution:**

Query to count trips with distance <= 1 mile between November 1st and December 1st, 2025:

```sql
SELECT COUNT(*)
FROM public.taxi_green_table green 
WHERE "lpep_pickup_datetime" BETWEEN '2025-11-01' AND '2025-12-01'
    AND "trip_distance" <= 1;
```

## Question 4: Longest Trip for Each Day

**Solution:**

Query to find the longest trip distance for each day (excluding trips >= 100 miles):

```sql
SELECT 
    DATE_PART('DAY', "lpep_pickup_datetime") AS day,
    MAX("trip_distance") AS longest_trip_distance
FROM public.taxi_green_table green
WHERE "trip_distance" < 100
GROUP BY DATE_PART('DAY', "lpep_pickup_datetime")
ORDER BY longest_trip_distance DESC;
```

## Question 5: Biggest Pickup Zone

**Solution:**

Query to find the pickup zone with the highest total amount on day 18:

```sql
SELECT 
    SUM("total_amount") AS total_amount,
    zone."Zone"
FROM public.taxi_green_table green
INNER JOIN public.taxi_zones_table zone
    ON green."PULocationID" = zone."LocationID"
WHERE DATE_PART('DAY', "lpep_pickup_datetime") = 18
GROUP BY zone."Zone"
ORDER BY total_amount DESC;
```

## Question 6: Largest Tip

**Solution:**

Query to find the drop-off zone with the largest tip amount for trips starting from 'East Harlem North':

```sql
SELECT 
    zone_dropoff."Zone",
    green."tip_amount"
FROM public.taxi_green_table green
INNER JOIN public.taxi_zones_table zone_pickup
    ON green."PULocationID" = zone_pickup."LocationID"
INNER JOIN public.taxi_zones_table zone_dropoff
    ON green."DOLocationID" = zone_dropoff."LocationID"
WHERE zone_pickup."Zone" = 'East Harlem North'
ORDER BY green."tip_amount" DESC;
```

## Question 7: Terraform Workflow

**Solution:**

The Terraform workflow consists of three main commands:

1. **Initialize Terraform:**
```bash
terraform init
```

2. **Apply infrastructure changes:**
```bash
terraform apply -auto-approve
```

3. **Destroy infrastructure:**
```bash
terraform destroy
```
